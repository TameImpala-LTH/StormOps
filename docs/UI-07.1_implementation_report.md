## 1. Root Cause of Previous Weak Visual Effect

Visual inspection of the UI-07 map revealed that in dark modes (specifically Vandal), the map presented a pale grey/beige appearance disconnected from StormOps' deep pitch-black UI. Diagnostic inspection revealed three distinct root causes:

1. **CSS Filter Math Inversion:** The previous filter evaluated `brightness(0.42) invert(1) hue-rotate(145deg) saturate(0.60) contrast(0.90) sepia(0.18)`:
   - Evaluated left-to-right, `brightness(0.42)` was executed *before* `invert(1)`.
   - OSM land tiles (`#f2efe9`, ~94% luminance) multiplied by 0.42 became ~40% grey (`#666462`).
   - The subsequent `invert(1)` inverted 40% grey into `1 - 0.40 = 0.60` (a **60% pale grey** `#999b9d`).
   - Subsequent `hue-rotate` had zero effect on low-saturation grey, and `sepia(0.18)` merely tinted it into a pale warm beige.
2. **Leaflet Pane Stacking & Sizing Failure:** In Leaflet, `.leaflet-map-pane` and its child `.leaflet-pane` have `position: absolute; left: 0; top: 0;` but **no width or height** (they are pure transform anchors).
   - Setting `atmoPane.style.width = '100%'; atmoPane.style.height = '100%'` computed against a 0px by 0px container.
   - The atmospheric overlay in `atmosphericPane` literally had `0px × 0px` dimensions and was visually nonexistent.
3. **Local Storage Drift & Desynchronization:** An independent `mapMode` state initialized from `localStorage.getItem('stormops_map_mode')` could lock the map into `'light'` mode even when the user toggled the global application theme to Vandal or Atheris.

---

## 2. Map Tile & Pane Architecture

The tile layer and atmospheric styling pipeline was redesigned with a robust, redundant architecture:

- **Viewport Overlay Layer:** Instead of placing the overlay in an un-dimensioned Leaflet transform pane, the atmospheric overlay `<div class="stormops-map-atmosphere-overlay" aria-hidden="true" />` is rendered inside the outer canvas container wrapper (`mapWrapperRef`) with `position: absolute; inset: 0; pointer-events: none; z-index: 450; border-radius: inherit;`.
- **CSS Variable / Attribute Inheritance (`data-map-theme`):** The map container declares `data-map-theme="vandal" | "atheris" | "midnight" | "light"`. High-specificity CSS rules target `.leaflet-tile-pane` and `.leaflet-container` directly, ensuring zero-FOUC immediate rendering even during tile reloads and zoom events.
- **Container Background Matching:** `.leaflet-container` background color is set to the theme's deepest base (`#090204` for Vandal, `#030712` for Atheris, `#070311` for Midnight), completely eliminating pale or white flashes between tile boundaries.

## 3. Vandal Implementation

- **Target:** Black / very dark base, deep maroon/burgundy atmosphere, neon red focal accent, dimmed map details, high-contrast readable geographic labels.
- **Tile Filter:**
  `invert(100%) sepia(100%) hue-rotate(305deg) saturate(2.4) brightness(0.62) contrast(1.32)`
  - `invert(100%)`: Transforms white/beige land into pitch black/dark slate.
  - `sepia(100%)` + `hue-rotate(305deg)`: Shifts hues from warm brown (35°) by 305° into pure deep crimson/burgundy (340°).
  - `saturate(2.4)`: Rich, dark wine undertones.
  - `brightness(0.62)` + `contrast(1.32)`: Deep blackish base with high-contrast rose-tinted silver text labels (`#fce7f3`) and readable dark roads.
- **Atmospheric Overlay:**
  `radial-gradient(ellipse at 50% 50%, rgba(225, 29, 72, 0.08) 0%, rgba(159, 18, 57, 0.16) 50%, rgba(9, 2, 4, 0.60) 100%)` with `box-shadow: inset 0 0 50px rgba(0, 0, 0, 0.85)`.
- **Focal Accent:** Neon red (`#ff2a55`) focal anchor dot, crimson aura, and red rain probability pill.

## 7. Marker Hierarchy Redesign

The marker hierarchy was completely restructured from a large floating card into a grounded geographic focal beacon:

1. **Primary Focal Point (`.stormops-focal-dot`):** A compact 10px circular anchor centered directly on the exact latitude/longitude coordinate with a 2px dark border and theme-accent glow.
2. **Concentric Beacon Rings (`.stormops-beacon-outer`, `.stormops-beacon-inner`):** Smooth, expanding concentric pulse rings centered precisely on the anchor coordinate.
3. **Localized Condition Aura (`.stormops-condition-halo`):** Restrained thermal gradient breathing around the coordinate without painting fake radar fields over the surrounding map.
4. **Adjacent Weather Label (`.stormops-focal-label`):** A compact pill offset to the top-right (`left: 10px; top: -14px`), displaying:
   - Bold monospace temperature numeral (`${temp}°C`) in theme accent color.
   - Clean location name (`locName`).
   - Compact rain probability pill (`${rain}%`).
