# WeatherGPT — Design Guidelines

## Design Direction

WeatherGPT should feel like a premium, modern weather intelligence product rather than a traditional weather dashboard or generic AI chatbot.

The design should prioritize:

- Minimalism
- Strong typography
- Generous whitespace
- Clear hierarchy
- Subtle motion
- Weather-driven visuals
- Context-aware information
- Ease of use

The interface should feel calm, intelligent, and trustworthy.

## Avoid Generic AI Aesthetics

Do not rely on:

- Excessive gradients
- Glowing effects
- Excessive glassmorphism
- Giant decorative elements
- Emoji-heavy interfaces
- Generic chatbot layouts
- Excessive rounded cards
- Unnecessary dashboard grids
- Visual clutter
- Decorative elements with no functional purpose

AI should be communicated primarily through the interaction experience, not visual clichés.

## Initial Screen

The initial screen should be intentionally minimal.

The primary focus should be the WeatherGPT identity and conversational input.

Avoid showing a large collection of empty weather cards before the user asks a question.

## Post-Query Experience

After the user submits a query, the interface should progressively reveal relevant information.

The general visual flow should be:

```text
Question
↓
Answer
↓
Relevant Weather Information
↓
Visualization
↓
Decision
↓
Explanation
