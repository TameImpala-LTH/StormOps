## 1. Executive Summary

Phase UI-06.1 is a targeted, corrective visual and interaction refinement pass that addresses three concrete product defects discovered after reviewing actual rendered production-like output from Phase UI-06:
1. **Header / Location Control Crowding:** On mobile and tablet/desktop viewports (768px–1200px), brand, docked search, live location/time, theme picker, and sign-in controls were contending for horizontal room, causing layout crowding and second-by-second layout jitter.
2. **Uneven Telemetry Spacing:** The core telemetry bar previously hardcoded a 5-column layout on desktop (`lg:grid-cols-5`). Because official Air Quality (AQI) advisories are only present for specific locations with active hazards, the vast majority of queries rendered only 4 metrics, leaving an awkward 20% empty gap on the right.
3. **WeatherGPT Verbosity for Rapid Scanning:** While rich in meteorologic detail, the previous WeatherGPT hero rendered long multi-paragraph prose blocks upfront, forcing users to read through extensive paragraphs before grasping the core forecast.

Phase UI-06.1 resolves all three issues completely while strictly preserving every underlying data model, API contract, and capability.

## 2. Header & Location Control Crowding Resolution

### 2.1 Problem Analysis
In `Header.tsx` and `LiveWeatherHeader.tsx`:
- The desktop layout rendered the brand, search bar, live location name, live ambient temperature badge, live time with ticking seconds (`hh:mm:ss AM/PM`), full date (`Wed, Sep 23, 2026`), theme toggle with active theme name, and user sign-in pill.
- On viewports between 768px and 1150px, this horizontal footprint exceeded 1050px, crowding out the docked search input and creating horizontal tension.
- The ticking seconds counter caused micro-shifts and layout jitter every single second in tabular font-free zones.

### 2.2 Implemented Architectural Fixes
1. **Live Clock Layout Jitter & Footprint Elimination:**
   - Updated `LiveWeatherHeader.tsx` time formatting from `hh:mm:ss` to clean hour and minute: `hour: 'numeric', minute: '2-digit'`. This reclaimed ~30px of horizontal room and eliminated 1-second layout jitter.
   - Refined date visibility: The full date string (`Wed, Sep 23, 2026 ·`) is now gated to `hidden xl:inline`, ensuring that on laptop, tablet, and mobile viewports, the clock remains hyper-compact without sacrificing time awareness.
   - Tightened location label truncation with responsive bounds: `max-w-[75px] md:max-w-[105px] xl:max-w-[140px] truncate`.
2. **Responsive Theme Selector:**
   - In `ThemeToggle.tsx`, the active theme text label (e.g., `Dark · Atheris`) is now gated with `<span className="hidden lg:inline">`.
   - On viewports below 1024px, the theme toggle displays as an elegant, compact icon button (32px), saving ~85px of horizontal width.
3. **Flex Zone Balance:**
   - Refined `Header.tsx` into three distinct flex zones:
     - Left (Brand & drawer toggle): `flex items-center space-x-2.5 sm:space-x-3 shrink-0`
     - Center (Docked Omnibar): `hidden md:flex flex-1 max-w-md mx-2 lg:mx-4 min-w-[180px]`
     - Right (Live telemetry, theme, auth): `flex items-center gap-1.5 sm:gap-2.5 shrink-0`
   - Brand kicker `WeatherGPT` is hidden on mobile screens (`hidden sm:inline`), keeping the top bar pristine on 375px screens.

## 3. Telemetry Spacing & Dynamic Grid Distribution

### 3.1 Problem Analysis
`WeatherTelemetry.tsx` hardcoded `grid-cols-2 sm:grid-cols-4 lg:grid-cols-5`. When an AQI advisory was not present (the typical case for clear or non-urban locations), only 4 metric cards rendered. Desktop CSS grid reserved space for 5 columns, leaving the entire right fifth blank and visually unanchored. Furthermore, mobile multi-row dividers suffered from Tailwind `divide-y` artifacts.

### 3.2 Dynamic Grid Implementation
- Dynamically calculates the presence of authoritative AQI data:
  ```typescript
  const aqi = extractAqiFromAdvisories(advisories);
  const gridLayoutClass = aqi
    ? 'grid-cols-2 sm:grid-cols-5'
    : 'grid-cols-2 sm:grid-cols-4';
  ```
- **Desktop (sm: and up):**
  - When AQI is absent: exactly 4 equal columns (`repeat(4, minmax(0, 1fr))`), each occupying 25% of the container width. Zero blank space.
  - When AQI is present: exactly 5 equal columns (`repeat(5, minmax(0, 1fr))`), each occupying 20% of the container width.
  - Vertical dividers are evenly spaced using `sm:divide-x sm:divide-[var(--border-subtle)]`.
- **Mobile (< 640px):**
  - Clean 2x2 grid layout (`grid-cols-2 gap-y-3 gap-x-3`) without jagged `divide-y` border anomalies.
  - When AQI is present, it cleanly spans full-width across both columns (`col-span-2 sm:col-span-1`) with a subtle top border separation.
- Graceful text truncation (`truncate`, `min-w-0`) applied to all metric secondary notes and peak descriptions.

## 4. WeatherGPT 3-Level Reading Hierarchy

To realize the core design vision — **Less UI. More Intelligence.** — the WeatherGPT hero surface has been structured into three distinct cognitive tiers:

```
┌──────────────────────────────────────────────────────────────┐
│ LEVEL 1: WHAT MATTERS (Synthesis Headline)                   │
│ 1–2 sentences answering "What is the main thing I need to     │
│ know right now?" + Decision / Confidence badge               │
├──────────────────────────────────────────────────────────────┤
│ LEVEL 2: BRIEFING (Scannable Bullet Structure)               │
│ [Conditions & Comfort] [Rain & Timing]                       │
│ [Wind & Air]          [Practical Advice]                     │
├──────────────────────────────────────────────────────────────┤
│ LEVEL 3: DETAILED INTERPRETATION (Collapsible Disclosure)    │
│ [Read Detailed Interpretation ▾]                             │
│ (Collapsed by default; reveals deep meteorological markdown) │
└──────────────────────────────────────────────────────────────┘
```

---

## 5. Level 1: What Matters (Synthesis Headline)

- **Purpose:** Provide instant situational awareness within 1–2 seconds.
- **Content:** Grounded in `response.key_insight` or deterministic meteorological synthesis (`generateDeterministicKeyInsight`).
- **Typography:** Prominent `text-xl sm:text-2xl lg:text-3xl font-light tracking-tight leading-snug max-w-3xl`.
- **Action Badge:** Accompanying decision recommendation badge (e.g., `umbrella recommended`, `high confidence`) strictly rendered only when computed by backend models.

---

## 6. Level 2: Briefing (Scannable Bullet Cards)

- **Purpose:** Deliver structured, high-signal meteorological interpretation without requiring the user to read prose paragraphs.
- **Card Matrix:** Rendered in an equal 2-column responsive grid (`grid-cols-1 sm:grid-cols-2 gap-2.5`):
  1. **Conditions & Comfort (Thermometer icon):** Interprets the actual feel, heat index, and humidity impact (e.g., *"Feels warmer than actual temperature (34°C vs 29°C) due to elevated humidity (78%)."*).
  2. **Rain & Timing (CloudRain icon):** Interprets rain probability, peak timing, or confirmed dry window (e.g., *"High likelihood of precipitation (85%), peaking around 18:00. Rain gear strongly recommended."*).
  3. **Wind & Air (Wind icon):** Interprets airflow velocity and physical resistance (e.g., *"Moderate breeze (18 km/h); gentle airflow with negligible impact."*).
  4. **Practical Advice (Lightbulb icon):** Actionable takeaway grounded in decision factors or commute/outdoor guidance (e.g., *"Carry an umbrella or rain poncho before heading out."*).
- **Styling:** Styled with `var(--surface-secondary)`, rounded 12px corners, subtle borders, and distinct micro-accent icons.

---

## 7. Level 3: Detailed Interpretation (Collapsible Disclosure)

- **Purpose:** Full deep-dive meteorological and decision reasoning remains 100% accessible to power users without cluttering the initial viewport.
- **Default State:** Collapsed by default (`isExpanded = false`). Reduces the initial vertical footprint of the briefing card by >60%.
- **Accessibility:**
  - Accessible `<button type="button" aria-expanded={isExpanded} aria-controls="weathergpt-detailed-interpretation">`.
  - Dynamic button text: `"Read Detailed Interpretation"` / `"Hide Detailed Interpretation"`.
  - Animated chevron indicator (`transition-transform duration-200 rotate-180`).
- **Content:** When expanded, renders the complete markdown text (`FormattedMarkdown`) cleanly partitioned with a top border.
