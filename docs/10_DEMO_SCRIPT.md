# Demo Script

## 1. Purpose

This document defines the primary hackathon demonstration flow for WeatherGPT.

The demo should show the product's core value quickly without depending on every feature being demonstrated.

---

## 2. Demo Goal

Demonstrate that WeatherGPT can:

- Understand natural-language weather questions.
- Retrieve real weather data.
- Interpret that data.
- Make practical decisions.
- Present the result through a clean interactive interface.

---

## 3. Primary Demo Flow

### Step 1 — Landing Screen

Start with the minimal WeatherGPT interface.

The screen should immediately communicate that the user can simply ask about the weather.

Example:

> "What do you want to know about the weather?"

---

### Step 2 — Natural-Language Query

Enter a practical question:

> "Should I carry an umbrella in Kolkata this evening?"

WeatherGPT should identify:

```text
Location: Kolkata
Time: This evening
Intent: Umbrella decision
