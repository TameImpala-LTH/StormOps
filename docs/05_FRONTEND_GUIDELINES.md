# WeatherGPT — Frontend Guidelines

## Purpose

The frontend should provide a minimal, premium, conversational weather experience.

The interface should feel intelligent without looking like a generic AI application or a traditional weather dashboard.

## Technology

The frontend should use:

- React
- TypeScript
- Vite
- Tailwind CSS
- Framer Motion

Additional libraries should only be introduced when they provide clear value.

## Core Experience

The primary interaction is:

```text
User opens WeatherGPT
        ↓
Sees minimal interface
        ↓
Asks a weather question
        ↓
Receives answer
        ↓
Relevant weather information appears
