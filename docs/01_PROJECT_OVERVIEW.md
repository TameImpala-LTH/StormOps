# WeatherGPT — Project Overview

> Detailed definition of the WeatherGPT product, its purpose, scope, users, goals, and core experience.

---

## 1. Purpose

WeatherGPT is a conversational weather intelligence platform that allows users to interact with real meteorological information using natural language.

The purpose of the project is to make weather information easier to access, understand, and act upon without requiring users to interpret complex weather dashboards, charts, or multiple data sources themselves.

WeatherGPT acts as an intelligence layer over meteorological data, allowing users to interact naturally without replacing the underlying meteorological data sources.

---

## 2. Core Concept

The central idea behind WeatherGPT is:

> **Users should be able to ask weather questions naturally and receive useful answers based on real weather data.**

Instead of asking users to interpret raw information such as:

- Temperature
- Rain probability
- Precipitation
- Wind speed
- Humidity
- Forecast charts
- Weather alerts

WeatherGPT allows users to ask practical questions such as:

```text
Will it rain tomorrow?

Should I carry an umbrella?

Is tomorrow good for an outdoor event?

How hot will it be this afternoon?

Which location has better weather today?

Why is tomorrow's weather considered risky?
